# Drop-In Custom Assets Folder

Drop your custom `.glb` 3D character/beast/boss models into `models/` and `.ogg`/`.wav` music/SFX into `audio/`, then map them in `www/js/config/servicesConfig.js` under `SERVICE_CONFIG.customAssets`.

Until custom files are added, **MILLER: VOID RUN** renders 100% out-of-the-box with its procedural low-poly 3D mesh factory and procedural adaptive 4-stem Web Audio synthesizer.
